GPT‑2 replica: twelve-head self-attention

A browser-only teaching sketch of a decoder block’s multi-head attention with twelve heads, the same head count as GPT‑2 small. It runs entirely in this page: tweak a prompt, pick a layer, and inspect causal attention maps.

What this page is for

The main nanochat.replica app trains a tiny GPT-style model and can load checkpoints in the browser after you export them with python -m llm.export_web … --out_dir public/models/tiny-gpt. That path wires real weights into the UI playground.

This HTML file is different on purpose: it uses small random matrices and a toy tokenizer so you can see twelve attention heatmaps update instantly without a checkpoint, a server, or a GPU. Think of it as the same shape of computation (masked multi-head attention inside stacked blocks) with synthetic numbers for pedagogy.

How multi-head self-attention works

Each token position has a vector of activations. Attention lets every position gather information from other positions—weighted by how relevant they are.

  • Queries, keys, and values (Q / K / V) — Three linear projections of the same hidden state. A query at position i “asks” which keys (which other positions) it should read from; each key is paired with a value vector that carries the information actually mixed in.
  • Scaled dot-product scores — Compatibility is measured by a dot product between query and key, then divided by √dhead so scores stay in a reasonable range as dimensions grow. Those scores become weights after a softmax.
  • Why multiple heads — One softmax mixes the whole sequence in a single pattern. Several heads let the model learn several mixing patterns in parallel (syntax vs. long-range reference vs. local repetition, and so on).
  • Concatenation and output projection — Each head produces a chunk of the same width as dmodel / nhead. Heads are concatenated back to width dmodel, then one more linear map fuses them into the block’s residual stream.

Attention(Q, K, V) = softmax(QKT / √dhead) V

How this ties to GPT‑2

GPT‑2 is a decoder-only transformer: every block is built for left-to-right language modeling. Self-attention is causally masked so position i cannot attend to future positions—each row of the heatmap only uses columns up to the diagonal.

Real GPT‑2 blocks also include feed-forward sublayers, full parameter tying, and other details omitted here. The repeating pattern you do see in both this demo and the full model is pre-norm → attention → residual add (and analogously for the FFN branch in complete implementations).
